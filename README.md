# Portal Escolar

> Um site inspirado em portais educacionais, com opções de matricula, ver a aparencia do campus, ver o tipo de ensino e ver quem são os docentes

---

## Funcionalidades

> os marcados com o x estão prontos

1. [x] `index.html` Pagina inicial com imagens e caminhos para cada uma das outras paginas
2. [x] `campus.html` Pagina demonstrando a aparencia do campus infernal
3. [x] `ensino.html` Pagina demontrando os horrores cosmicos lecionadosna escola
4. [x] `formulario.html` Pagina com um formulário de pact... Matricula

5. [x] Pagina desmonstrando quem são nossos professores/ sacerdotes de horroes ancestrais

## Como Executar o Projeto

### Metodo 1: _Direto no Navegador_

1. Baixe ou clone os arquivos na sua maquina
2. Dê duplo clique no arquivo `index.html`
3. Espere o Navegador abrir

### Metodo 2: _Com a extenção Go live/Live server (Recomendado no VScode)_

1. Abra a pasta do projeto no VS Code.
2. Certifique-se de ter a extensão **Live Server** instalada.
3. Abra o arquivo `index.html`.
4. Clique no botão **"Go Live"** no canto inferior direito da barra de status do VS Code para abrir a página com atualização automática ao salvar.

### Metodo 3: _Visualização Online_
