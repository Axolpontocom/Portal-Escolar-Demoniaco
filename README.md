## Como Executar o Projeto

### Metodo 1: *Direto no Navegador*

1. Baixe ou clone os arquivos na sua maquina
2. Dê duplo clique no arquivo `index.html`
3. Espere o Navegador abrir

### Metodo 2: *Com a extenção Go live/Live server (Recomendado no VScode)*

1. Abra a pasta do projeto no VS Code.
2. Certifique-se de ter a extensão **Live Server** instalada.
3. Abra o arquivo `index.html`.
4. Clique no botão **"Go Live"** no canto inferior direito da barra de status do VS Code para abrir a página com atualização automática ao salvar.
